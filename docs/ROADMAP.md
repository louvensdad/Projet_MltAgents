# Roadmap

## Fase 1: Fundação
- Estruturação do repositório
- Definição do papel de cada agente
- Documentação base

## Fase 2: Comunicação Inter-Agentes
- Configurar base do Orchestrator
- Fluxo de mensagens e estado entre agentes

## Fase 3: Geração de Código Backend
- Geração de API e Banco de dados funcional
- Implementação inicial pelo Backend Agent

## Fase 4: Geração de Código Frontend
- Geração de UI com Next.js
- Integração com a API gerada

## Fase 5: Validação e Deploy
- CI/CD pelo DevOps Agent
- Avaliações de Segurança e Qualidade
