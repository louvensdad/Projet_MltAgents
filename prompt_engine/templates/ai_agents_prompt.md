# PROMPT MASTER - AI Agents

## Goal
Generate a multi-agent AI system with tools, memory, workflows, guardrails and evaluation.

## Required rules
- Define agents, tools, memory, workflows, llm_provider, guardrails and evaluation
- Use structured logs and traceability
- Include safety layers, prompt boundaries and fallback behavior
- Include tests and documentation
- Keep secrets server-side only

## Forbidden
- Hardcoded API keys
- Missing guardrails
- Missing logs
- Unsafe tools
- Silent failures
