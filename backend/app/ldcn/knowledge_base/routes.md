# Routes

- `/wizard`: fluxo guiado para definir requisitos e gerar projeto.
- `/templates`: galeria de templates disponiveis.
- `/downloads`: area para baixar pacotes, ZIPs e artefatos gerados.
- `/validation-center`: area para validacao tecnica, qualidade e seguranca.
- `/ai-models`: area para modos de IA e Agent Boost.
- `/create`: entrada para criacao direta de projeto.
