# Stacks

- `fastapi`: indicado para APIs, automacao, agentes, workflows e servicos leves com entrega rapida.
- `spring_boot`: indicado para cenarios enterprise, dominios complexos, governanca forte e integracoes pesadas.
- `static_site`: indicado para landing pages, sites institucionais, SEO e experiencia simples.
- `nextjs`: indicado para portais, dashboards e interfaces ricas com SSR/SPA.
- `react`: indicado para frontends ricos quando a estrutura nao exige o pacote completo de Next.js.
